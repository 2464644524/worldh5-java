# 世界H5 十开控制台

《世界H5》原 APK（5 开 WebView 辅助壳）的电脑版重制：Java + Swing 控制台，通过
Playwright 驱动本机 Microsoft Edge，每个账号使用独立的持久化用户目录，实现
Cookie、LocalStorage、缓存互相隔离，支持最多 10 开。

## 运行环境

- Windows 10/11
- JDK 17 或更高版本（当前机器使用 JDK 25）
- 已安装 Microsoft Edge（Playwright 通过 `setChannel("msedge")` 调用系统 Edge）

## 启动方式

双击或在项目目录执行：

```bat
run.cmd
```

脚本会先编译再通过 `exec:java` 启动控制台。第一次运行会下载 Playwright 浏览器驱动，
需要联网，之后即可离线使用。

## 目录结构

```
world-desktop/
├── data/
│   ├── accounts.json            # 10 个账号的配置（自动生成）
│   └── profiles/
│       ├── account-01/          # 账号1独立 Edge Profile（Cookie/缓存隔离）
│       ├── account-02/
│       └── ... account-10/
├── src/main/resources/scripts/  # 从原 APK 原样抽取的辅助 JS
└── run.cmd
```

每个账号对应一个独立 Profile 目录，账号之间不共享登录态。删除某个 `account-XX`
目录相当于让该账号重新登录。

## 使用流程（首次）

1. 启动控制台，选择账号（01–10），填写备注、选择渠道（天宇 / 官版 / 小七）。
2. 点“打开当前账号”，会弹出独立 Edge 窗口。
3. 官服会自动填写账号密码；天宇存号直链打开后会自动选择角色并点击进入游戏。
   遇到图形验证码、创建角色或密码错误时，按日志提示手动处理。检测到游戏 Frame 且
   `xself / Control / nato` 就绪后，控制台日志出现“脚本环境已注入”，辅助脚本自动生效。
4. 进入游戏后可点“使用当前URL存号”，把游戏直链保存到配置，下次打开直接进游戏。
5. 单账号验证稳定后，再用“全部打开(10开)”批量启动（有确认弹窗，不会自动全开）。

## 游戏操作记录

进入游戏并注入辅助环境后，控制台会旁路记录游戏内操作，长期追加到：

```text
data/操作记录.txt
```

记录内容包括：

- 手动点击、拖动的游戏归一化坐标；
- 操作时所在地图、是否城内、角色坐标；
- 打开/关闭的游戏面板；
- NPC 任务菜单、接取/提交任务交互；
- 客户端发出的游戏网络指令（优先记录 `MsgHandler.createXxx` 工厂名和参数摘要）。

该功能只观察和记录，不点击、不改游戏状态、不发送网络包；不记录 URL query/hash、token、账号或密码。高频点击和自动任务可能让文件增长较快，可按需定期另存或清空。

## 登录流程追踪

新窗口从渠道打开到进入游戏期间，会在控制台输出 `[登录]` 阶段日志，并追加到
`data/登录流程.txt`。日志包含页面跳转、登录/验证码/选角阶段、按钮文本和画布归一化点击位置；
不会记录 URL 参数、输入框内容或密码。该日志用于复盘人工进游戏流程，并校准后续自动登录。

## 自动选角进入游戏

- 官服：账号密码提交后，自动选择正常角色并请求进入游戏。
- 天宇：使用 Excel/存号里的游戏 URL 打开，不填写账号密码；加载页会先自动点击“进入游戏”，
  到选角界面后优先调用游戏对象进入，若对象接口未响应，再按实测画布坐标点击选角页“进入游戏”。
- 加载页第一次点击的坐标是 `(0.436,0.870)`，选角页第二次点击的坐标是 `(0.557,0.929)`；
- 只有真正进入游戏、`xself / Control / nato` 就绪后，才会注入加速、自动任务、任务日志等辅助脚本；
  选角阶段不会提前注入。
## 单号/批量托管与自动切号

“当前账号”区的“托管”按钮用于从当前选中账号开始自动闭环：自动打开/等待登录、等待进入游戏
和脚本注入、先判断是否在城内再进城、随后开启自动任务并持续守护。运行中按钮会变为
“停管 队列位置/总数·槽位”，点击后停止自动/刷怪/跟随但保留浏览器窗口。

“批量”区新增“全托”按钮：导号选中 5 个账号后点击，会从本次导号队列第一个账号开始，按
`01 → 02 → 03 → 04 → 05` 的顺序串行托管。当前账号连续约 60 分钟无自动主线可接/可交后，
自动停止脚本、关闭当前账号，并切换到队列下一个账号；队列处理完后自动停止托管。

自动任务确认运行后，任务快照从第 3 分钟开始检查，之后固定每 3 分钟一次：

- 存在游戏原生自动任务可接或可交：无任务计数清零；
- 没有自动主线可接/可交：无任务计数 `+1`；
- 连续 20 次无任务（约 60 分钟保底）：自动停止并关闭当前账号，切换到队列下一个账号；
- 快照读取失败不计数，60 秒后重试，避免网络抖动导致误切号；
- 队列全部处理完后停止托管并保留最后一个浏览器窗口。

如果先通过“导号”选择 A/C/D 等账号，单号“托管”和批量“全托”都会按本次导号槽位顺序排队；
从中间某个账号点“托管”，队列会从当前账号开始，再依次处理队列内后续账号。手动单独打开时，
则按本地已具备天宇直链或官服账号密码的槽位生成兜底队列。

## 任务快照监控

单号托管进入“自动任务运行中”后，控制台会定时读取游戏内存中的任务状态：

- 已接任务：读取 `xself.missionList`；
- 当前地图 NPC 任务：读取 `xworld.npcList[*].missionList / missions`；
- 已打开 NPC 对话时补充读取 `PanelManager.npcDialogue`；
- 状态严格按游戏原生 `MissionConst.CAN_ACCEPT` / `CAN_SUBMIT` 判断；
- 自动候选过滤对齐游戏原生 `AutoGamer.isMissionCanDo`：城市公告/介绍、一键任务、
  国家分配、直交/无限提交、嵌套任务、押镖、随机任务等不计入自动主线；
- `CAN_SUBMIT` 可交任务始终计入“仍有自动任务”，避免中途任务被误判为空。

控制台输出前缀为 `[任务快照]`，同时追加到本机 `data/任务快照.txt`。日志会同时展示
“主线可接/主线可交”和“忽略城市/支线”数量。该功能只读，不点击、不接任务、不发网络请求。
## 功能按钮（对应原 APK）

- 自动：`TestAutoGame.start()`
- 刷怪：`TestRefreshGame.start(4000)`
- 跟随：`TestLoopGame.start()`
- 停止脚本：依次 stop 上述三个
- 进城：`City.doEnterCity(xself.getId())`
- 微端奖励：`nato.Network.sendCmd(MsgHandler.createDrawMicroReward())`
- 自动清背包：进入游戏后始终加载 `auto_clear_bag.js`，只有勾选后才启动定时清理

## 关键实现说明

- Playwright 的所有阻塞调用都在单线程 `playwright-worker` 上串行执行，
  Swing 事件线程不被阻塞。
- 后台线程每秒轮询一次所有已打开账号，游戏 Frame 就绪后只注入一次脚本。
- 注入脚本使用间接 `eval`（`(0,eval)(...)`）执行，保证脚本里的
  `var TestAutoGame = ...` 等声明挂到全局 `window`，与 Android WebView
  的 `evaluateJavascript` 行为一致。
- 天宇、小七渠道通过 `addInitScript` 注入原 APK 的 iframe 跳转脚本，
  让外层渠道页自动跳到游戏 Frame。

## 注意事项与风险

- 官版 / 小七地址为 HTTP 明文渠道，已通过 `setIgnoreHTTPSErrors` 处理，
  请仅在可信网络环境使用。
- 10 开内存占用较高，建议单开、双开逐步验证后再开满，并留意机器内存。
- 辅助脚本会改变游戏行为，存在封号风险，请自行评估后使用。
- 控制台不会自动批量开号，必须手动确认“全部打开”。
## Excel 导号自动上号（最新）

1. 点右侧辅助栏“批量”里的“模板”，生成 `data/账号导入模板.xlsx`。
2. Excel 按 `账号 / 密码 / 备注` 填写；也支持常见表头：`账户 / 用户名 / account / username`、`password / pwd / 登录密码`。
3. 支持 `.xlsx / .xlsm / .xls / .csv`；CSV 自动兼容 UTF-8 和 GBK。
4. 点“导号”选择账号表，勾选要登录的账号；勾选顺序就是 01–10 槽位顺序，最多 10 个。
5. 点“登录选中账号”后，会自动重开对应 Edge：官服清理旧 Cookie/本地账号缓存、填写账号密码、提交并选角进入；天宇读取存号 URL，到选角界面后自动选择角色并进入游戏。
6. 图形验证码、密码错误、创建角色等无法自动判断的情况会在日志提示，需要手动处理。

密码只保存在本次程序运行内存中，不写入 `data/accounts.json`。天宇账号依赖 Excel/存号 URL 中的登录态，日志不会记录 URL query/hash。测试前请关闭旧控制台和旧游戏窗口后重新双击 `run.cmd`。
